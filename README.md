# Universal Music Transfer

Локальный сервис для переноса лайков и плейлистов между музыкальными сервисами. Работает у вас на компьютере
(в браузере по адресу `http://127.0.0.1:8890`), токены и данные никуда не отправляются, кроме самих музыкальных сервисов.

Это развитие проекта [yandex-music-to-spotify](https://github.com/sparrrxw/yandex-music-to-spotify): тот же движок
(поиск по ISRC, кэш, пауза при исчерпании квоты, ручная проверка спорных треков, синхронизация новых лайков),
но источники и приёмники теперь подключаемые.

## Какие сервисы поддерживаются (ноябрь 2026)

| Сервис | Откуда (читать) | Куда (записывать) | Как входить | Что нужно |
|---|---|---|---|---|
| Яндекс Музыка | ✅ лайки, свои плейлисты, открытые плейлисты по ссылке | ✅ «Мне нравится», плейлисты | токен из адресной строки | только аккаунт |
| Spotify | ✅ «Любимые треки», свои плейлисты | ✅ «Любимые треки», плейлисты | свой Client ID + вход через Spotify | Premium у владельца приложения |
| YouTube Music | ✅ «Понравившиеся», плейлисты | ✅ лайки, плейлисты | заголовки запроса из браузера | только аккаунт |
| TIDAL | ✅ избранное, плейлисты | ✅ избранное, плейлисты | вход по ссылке (как на ТВ) | подписка TIDAL |
| Deezer | ✅ открытые плейлисты и профили по ссылке | ❌ | не нужен | — |
| CSV-файл | ✅ любой файл с колонками «название / артист» | ✅ выгрузка в CSV | — | — |
| Apple Music | ❌ | ❌ (обход через CSV) | — | см. ниже |
| VK Музыка | ❌ | ❌ | — | см. ниже |
| SoundCloud | ❌ | ❌ | — | см. ниже |

### Почему некоторых сервисов нет

- **Apple Music.** Официальный Apple Music API требует платного членства Apple Developer Program (99 $ в год):
  без него нельзя выпустить developer token, а без токена нельзя ни читать, ни писать медиатеку. Обходной путь
  уже есть: на главной нажмите «Скачать CSV» и загрузите файл в Apple Music через TuneMyMusic или Soundiiz.
  Если у вас появится аккаунт разработчика Apple, поддержку можно добавить.
- **VK Музыка.** У ВКонтакте нет официального API для аудио; сторонние программы пользуются неофициальными токенами
  (Kate Mobile и т. п.), это нарушает правила VK и грозит блокировкой. С сентября 2026 VK к тому же ввёл
  месячные лимиты и платный доступ к API для сторонних клиентов.
- **SoundCloud.** API формально открыт, но ключ приложения выдают только при подписке Artist Pro. Если такой ключ
  у вас есть, сервис можно добавить по тому же образцу.
- **Deezer (запись).** С июня 2025 Deezer не даёт частным лицам создавать приложения для API (официальный ответ
  поддержки, октябрь 2025: из-за злоупотреблений). Публичное чтение работает без входа, поэтому Deezer есть
  как источник. Запись возможна только неофициально, через cookie `arl`; это можно добавить позже.
- **YouTube Music и TIDAL** работают через неофициальные библиотеки
  ([ytmusicapi](https://github.com/sigma67/ytmusicapi), [tidalapi](https://github.com/EbbLabs/python-tidal)),
  потому что официальных API для библиотеки пользователя у них либо нет, либо они требуют регистрации партнёра.
  Если сервис что-то поменяет, нужно будет обновить библиотеку: `uv lock --upgrade-package ytmusicapi` (или tidalapi) и перезапустить.

## Запуск на Windows

1. Один раз установите [uv](https://docs.astral.sh/uv/) командой в PowerShell:
   ```
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
2. Дважды кликните `START.bat`. В первый раз uv сам скачает Python и библиотеки (около минуты).
3. Откроется браузер на `http://127.0.0.1:8890`. Если открылся не Brave, скопируйте адрес в Brave.

Остановить сервис: закройте чёрное окно. Все данные лежат в папке `data` рядом (её можно удалить, чтобы начать с нуля).

Старый сервис «Яндекс → Spotify» работает на порту 8888, этот на 8890: их можно запускать одновременно.

## Как пользоваться

1. **Подключите сервисы.** На главной в блоке «Сервисы» нажмите на нужный и следуйте инструкции на его странице.
2. **Откуда.** «Добавить источник» → выберите сервис и отметьте лайки и плейлисты, либо вставьте ссылку на открытый
   плейлист любого сервиса, либо загрузите CSV.
3. **Куда.** Выберите сервис-приёмник. Один и тот же источник можно перенести в несколько сервисов по очереди:
   найденное хранится отдельно для каждого приёмника.
4. **Найти треки.** Поиск идёт по всем загруженным спискам: сначала по ISRC (Spotify, TIDAL), потом по артисту и
   названию, потом латиницей. Дубли (один трек в нескольких плейлистах) ищутся один раз.
5. **Проверить спорные.** Выберите верный вариант, поищите своим запросом или вставьте ссылку на трек. Решение
   применяется к тому же треку во всех списках.
6. **Перенести** в лайки и/или в плейлист. Лайки ставятся от старых к новым, чтобы сверху были самые свежие, как в
   источнике. Повторный перенос досылает только новое.
7. **Синхронизация новых лайков:** одна кнопка забирает свежие лайки из каждого источника-«лайков» и переносит их
   туда же и так же, как в прошлый раз.

Не найденные треки можно скачать в CSV (`Ненайденные CSV`) и загрузить в TuneMyMusic.

### Квоты и паузы

Если сервис начинает отказывать из-за лимита запросов (у Spotify это дневная квота, ответ `429 QUOTA_EXCEEDED`),
задача встаёт на паузу и показывает, когда можно продолжить. Нажмите ту же кнопку после этого времени: работа
продолжится с того же места, уже найденное не ищется повторно (кэш). Дневной лимит и паузу между запросами можно
настроить на странице каждого сервиса.

## Подключение сервисов коротко

- **Яндекс Музыка:** «Получить токен» → войти → скопировать весь адрес с `#access_token=…` → вставить.
- **Spotify:** нужен свой Client ID с [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard).
  Spotify разрешает одно приложение на человека, поэтому используйте то же, что и для старого сервиса, и просто
  добавьте в нём Redirect URI `http://127.0.0.1:8890/callback/spotify`. Владельцу приложения нужен Premium,
  остальных (до 5 человек) добавьте в User Management.
- **YouTube Music:** в Brave на music.youtube.com нажмите F12 → Network → фильтр `browse` → кликните «Библиотека» →
  правой кнопкой по запросу `browse` → Copy → Copy request headers → вставить на странице сервиса.
- **TIDAL:** «Войти в TIDAL» → открыть показанную ссылку → подтвердить.

## Для разработчика

- Python 3.12, FastAPI, Jinja2, SQLite. Зависимости и Python ставит uv (`pyproject.toml`, `uv.lock`).
- Тесты: `uv run pytest`.
- Каждый сервис — класс в `app/providers/`, наследник `Provider` (`base.py`). Чтобы добавить сервис, реализуйте
  чтение (`list_collections`, `fetch`, `parse_link`) и/или запись (`search`, `save_likes`, `create_playlist`,
  `add_to_playlist`), добавьте класс в `ALL` в `app/providers/__init__.py` и страницу подключения в `app/templates/`.
- Таблицы: `tracks` (треки источников), `matches` (сопоставление трека с конкретным приёмником), `search_cache`
  (кэш поиска по каждому сервису), `kv` (настройки и токены).
